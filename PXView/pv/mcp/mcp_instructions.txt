PXView is a multi-mode signal analyzer with 4 work modes.
This server provides 45 tools organized in 4 tiers.

## Work Modes

PXView operates in one of four work modes. You MUST switch to the desired
mode before configuring channels, triggers, or probes:

  0 = Logic  — Digital signal analysis (digital channels, logic triggers,
               glitch filter, RLE compression, digital threshold)
  1 = DSO    — Digital Storage Oscilloscope (oscilloscope channels, DSO
               triggers with source/slope/holdoff, probe config, math/
               spectrum/lissajous)
  2 = Analog — Analog/DAQ acquisition (analog channels, probe config,
               math/spectrum/lissajous)
  3 = MSO    — Mixed Signal Oscilloscope (both digital + analog channels,
               all features available)

## Default Behavior

If the user does not specify a work mode, default to Logic mode (0).
Logic mode covers the most common use cases: digital signal analysis,
protocol decoding (SPI, I2C, UART, CAN, etc.), and digital triggers.

Do NOT ask the user which mode to use. Instead, infer from context:
- User mentions oscilloscope/probe/vdiv/coupling/math/spectrum → DSO mode (1)
- User mentions analog/DAQ/sensor → Analog mode (2)
- User explicitly needs mixed digital + analog → MSO mode (3)
- Otherwise → Logic mode (0), proceed silently

Only ask the user to clarify if their request is genuinely ambiguous
across multiple modes and the correct choice cannot be inferred.

## Standard Workflow

1. get_devices                    — discover available devices and their IDs
2. create_session(deviceId)       — create a session for the device
3. get_supported_work_modes       — check which modes the device supports
4. switch_work_mode(mode)         — select the work mode (MUST do before
                                     configuring channels/triggers/probes)
5. get_channels                   — see available channels for current mode
6. configure_channel              — enable/disable channels, set names
7. set_sample_config              — set sample rate/limit/timebase/collect mode
8. configure_trigger              — set trigger (auto-dispatches to LogicTrigger
                                     or DsoTrigger based on current mode)
9. configure_probe                — set probe/vdiv/coupling (DSO/Analog/MSO only)
10. configure_glitch_filter       — set glitch filter (Logic/MSO only)
11. add_analyzer                  — add protocol decoder (Logic/MSO only,
                                     before start_capture for auto-decode)
12. start_capture                 — begin acquisition (trigger config set separately)
13. wait_capture                  — wait for completion (non-stream mode)
14. get_samples                   — read raw samples (channelType must match mode)
15. get_analyzer_results          — read decoded protocol data
16. export_raw_data / export_data_table_csv — export results

## Mode-Specific Constraints

These tools will return an error if called in the wrong mode:

  configure_probe:        Only in DSO/Analog/MSO mode
  configure_glitch_filter: Only in Logic/MSO mode
  add_analyzer:           Only in Logic/MSO mode (decoders need digital channels)
  get_math_results:       Only in DSO/Analog/MSO mode
  get_spectrum_results:   Only in DSO/Analog/MSO mode
  get_lissajous_results:  Only in DSO/Analog/MSO mode

The error message will tell you which mode to switch to.

## Capture Modes

  Buffer mode: Traditional fixed-length capture. Use captureMode="timed" with
               durationSeconds, or captureMode="manual".
  Stream mode: Continuous acquisition with no sample limit. Use
               captureMode="stream" and call stop_capture to end.
               In Stream mode, durationSeconds and sampleCount are IGNORED.

## Common Error Patterns

  "No active session": Call create_session or connect_device first.
  "Capture in progress": Call stop_capture or wait_capture first.
  "No data": Capture hasn't completed or no channels were enabled.
  "Config not supported": The device doesn't support the requested config.
  "Probe config not available in Logic mode": Call switch_work_mode(1) or (2).
  "Glitch filter not available in DSO mode": Call switch_work_mode(0).

## Sessions

PXView supports multiple sessions. Each session has its own device,
channels, and capture state. Use create_session to create a new one,
set_active_session to switch between them, and list_sessions to see all.
